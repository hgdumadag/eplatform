## What You Should Already Know

Before studying coordinate position, make sure these ideas feel familiar:

- A number line uses positive and negative numbers to show position.
- Moving right usually increases a horizontal value.
- Moving left usually decreases a horizontal value.
- Moving up usually increases a vertical value.
- Moving down usually decreases a vertical value.

## Key Vocabulary

| Term | Meaning |
|---|---|
| Cartesian plane | A flat grid formed by a horizontal x-axis and a vertical y-axis |
| x-axis | The horizontal number line |
| y-axis | The vertical number line |
| Origin | The point where the axes meet, written as (0, 0) |
| Ordered pair | A coordinate pair written as (x, y) |
| x-coordinate | The first number in an ordered pair; it tells left or right movement |
| y-coordinate | The second number in an ordered pair; it tells up or down movement |
| Quadrant | One of the four regions formed by the x-axis and y-axis |

> [!IMPORTANT] Core Idea
>
> A point's position is written as **(x, y)**. Move horizontally first using x, then vertically using y.

## Visual Introduction

The Cartesian plane combines two number lines. The x-axis measures left and right position. The y-axis measures up and down position.

![Cartesian plane with axes and origin](/content/grade-10/math/quarter-1/topic-coordinate-position/images/inline-01-cartesian-plane-with-axes-and-origin.svg)

## Main Concept Explanation

### 1. Read an Ordered Pair as (x, y)

An ordered pair has two numbers:

$$ (x, y) $$

- The **x-coordinate** tells how far left or right to move from the origin.
- The **y-coordinate** tells how far up or down to move from the origin.

For example, the point (3, 2) means:

1. Start at (0, 0).
2. Move 3 units right.
3. Move 2 units up.

![Plotting the point three comma two](/content/grade-10/math/quarter-1/topic-coordinate-position/images/inline-02-plotting-the-point-three-comma-two.svg)

> [!TIP] Reading Coordinates
>
> Say the coordinate as "x first, y second." This prevents the most common reversal error.

### 2. Signs Tell Direction

The signs of the coordinates tell which direction to move.

| Coordinate sign | Direction |
|---|---|
| x is positive | Move right |
| x is negative | Move left |
| y is positive | Move up |
| y is negative | Move down |

For example:

- (-4, 1): 4 units left, 1 unit up
- (2, -5): 2 units right, 5 units down
- (-3, -2): 3 units left, 2 units down

### 3. Quadrants Describe Regions

The x-axis and y-axis divide the plane into four quadrants.

![Four quadrants of the Cartesian plane](/content/grade-10/math/quarter-1/topic-coordinate-position/images/inline-03-four-quadrants-of-the-cartesian-plane.svg)

> [!WARNING] Axis Reminder
>
> A point on an axis is **not** in a quadrant. For example, (0, 5) is on the y-axis, and (-2, 0) is on the x-axis.

## Rule Box / Formula Box

Use these rules for coordinate position:

| Position clue | What it means |
|---|---|
| (x, y) | x first, y second |
| x > 0 | Right of the y-axis |
| x < 0 | Left of the y-axis |
| y > 0 | Above the x-axis |
| y < 0 | Below the x-axis |
| x = 0 | On the y-axis |
| y = 0 | On the x-axis |
| (0, 0) | Origin |

Quadrant signs:

| Quadrant | Sign pattern |
|---|---|
| I | (+, +) |
| II | (-, +) |
| III | (-, -) |
| IV | (+, -) |

## Worked Examples

### Example 1: Describe a Point

**Problem:** Describe the position of A(5, -2).

**Solution:**

The x-coordinate is 5, so the point is 5 units right of the origin.

The y-coordinate is -2, so the point is 2 units below the origin.

**Answer:** A(5, -2) is 5 units right and 2 units down from the origin. It is in Quadrant IV.

### Example 2: Identify the Quadrant

**Problem:** Which quadrant contains B(-6, 4)?

**Solution:**

The x-coordinate is negative, so the point is left of the y-axis.

The y-coordinate is positive, so the point is above the x-axis.

The sign pattern is (-, +).

**Answer:** Quadrant II

### Example 3: Use Coordinates as Evidence

**Problem:** Points C(-3, 2) and D(4, 2) are plotted in the plane. Describe how their positions compare.

![Two points with the same y-coordinate](/content/grade-10/math/quarter-1/topic-coordinate-position/images/inline-04-two-points-with-the-same-y-coordinate.svg)

**Solution:**

Both points have y-coordinate 2, so they are on the same horizontal line. D has the greater x-coordinate, so D is farther right.

**Answer:** C and D are horizontally aligned. D is to the right of C.

## Misconception Alerts

> [!WARNING] Misconception 1: Reversing the Order
>
> The point (2, -5) is not the same as (-5, 2). The first number is always x, and the second number is always y.

> [!WARNING] Misconception 2: Putting Axis Points in Quadrants
>
> Points on the axes are not in Quadrants I, II, III, or IV. A zero coordinate usually signals an axis point.

> [!WARNING] Misconception 3: Thinking "Bigger" Always Means Higher
>
> Higher depends on the y-coordinate. Farther right depends on the x-coordinate.

## Error Analysis

A student describes R(-4, 3) this way:

> "R is 4 units right and 3 units up, so it is in Quadrant I."

What is the mistake?

<details>
<summary>Reveal mistake explanation</summary>

The x-coordinate is -4, so the point is 4 units **left**, not right. The correct description is: R is 4 units left and 3 units up from the origin, so it is in Quadrant II.
</details>

## Extension Challenge

Point A is (-3, 2). Point B is 6 units to the right of A and 5 units below A.

Find the coordinates of B.

<details>
<summary>Reveal hint</summary>

Moving right changes x by +6. Moving below changes y by -5.
</details>

<details>
<summary>Reveal full solution</summary>

Start with A(-3, 2).

For x: -3 + 6 = 3.

For y: 2 - 5 = -3.

So B is **(3, -3)**.
</details>

## Final Summary

The Cartesian plane uses two perpendicular number lines to describe position. Coordinates are written as (x, y): x tells left or right movement, and y tells up or down movement. The signs of x and y help you name quadrants, while zero coordinates identify points on the axes.
