## Key Vocabulary

| Term | Meaning |
|---|---|
| Percentile rank | The percent of values in a data set that are below a given score, unless a problem states a different convention |
| Given score | The score whose standing you want to describe |
| Below-score convention | Counting only values strictly less than the given score |
| At-or-below convention | Counting values less than or equal to the given score |
| Relative standing | How a value compares with the rest of the data set |
| Interpretation | A sentence that explains what the computed rank means in the situation |

> [!TARGET] Target Skill
>
> Read the data set, count the correct values, divide by the total number of values, multiply by 100, and explain the result in context.

## Visual Introduction

Percentile rank is a way to describe position in a data set. It does not tell the score itself. It tells how many values are below that score compared with the whole group.

![Number line showing scores below 82 and the target score](/content/grade-10/math/quarter-2/topic-statistics-lesson-8-percentile-rank/images/percentile-rank-number-line.svg)

For the ordered scores

$$
60, 64, 68, 70, 75, 78, 82, 86, 90, 94
$$

the score \(82\) has six scores below it. Since there are ten scores total, \(82\) is at the 60th percentile using the below-score convention.

## Main Concept 1: The Below-Score Formula

Use this rule unless the problem says to count values at or below the score.

$$
\text{Percentile rank}=\frac{\text{number of values below the score}}{\text{total number of values}}\times 100
$$

![Percentile rank formula flow from score to interpretation](/content/grade-10/math/quarter-2/topic-statistics-lesson-8-percentile-rank/images/formula-flow.svg)

The steps are:

1. Order the data if it is not already ordered.
2. Count the values below the given score.
3. Divide by the total number of values.
4. Multiply by \(100\).
5. Write a sentence in context.

> [!TIP] Phrase To Remember
>
> Count below, divide by total, then explain the standing.

## Worked Example

**Problem:** A Grade 10 class recorded these quiz scores:

$$
60, 64, 68, 70, 75, 78, 82, 86, 90, 94
$$

Find the percentile rank of a score of \(82\) using the below-score convention.

![Ordered table used to count scores below a target score](/content/grade-10/math/quarter-2/topic-statistics-lesson-8-percentile-rank/images/score-table-count.svg)

**Step 1: Count values below \(82\).**

The scores below \(82\) are:

$$
60, 64, 68, 70, 75, 78
$$

There are \(6\) scores below \(82\).

**Step 2: Identify the total.**

There are \(10\) scores in the data set.

**Step 3: Substitute into the formula.**

$$
\text{Percentile rank}=\frac{6}{10}\times 100=60
$$

**Step 4: Interpret.**

> [!EXAMPLE] Complete Answer
>
> A score of \(82\) is at the 60th percentile. This means \(82\) is higher than 60% of the quiz scores in this class.

## Main Concept 2: Below vs. At Or Below

Some textbooks and reports use an at-or-below rule. That rule counts the given score itself.

![Comparison of below-score and at-or-below percentile rank conventions](/content/grade-10/math/quarter-2/topic-statistics-lesson-8-percentile-rank/images/below-vs-at-below.svg)

For the same score of \(82\):

| Convention | Count | Computation | Percentile rank |
|---|---:|---|---:|
| Below-score | 6 scores below \(82\) | \(\frac{6}{10}\times100\) | 60th percentile |
| At-or-below | 7 scores at or below \(82\) | \(\frac{7}{10}\times100\) | 70th percentile |

> [!WARNING] Convention Alert
>
> Always check whether the problem says "below" or "at or below." The counting rule changes the answer.

## Main Concept 3: What Percentile Rank Means

A percentile rank is not the same as a test score.

- A score of \(82\) is the actual score.
- The 60th percentile describes relative standing.
- The interpretation must mention the data set or group.

![Interpretation card showing score, percentile rank, and context sentence](/content/grade-10/math/quarter-2/topic-statistics-lesson-8-percentile-rank/images/interpretation-card.svg)

Strong interpretation:

> In this class, a score of \(82\) is higher than 60% of the quiz scores.

Weak interpretation:

> The answer is 60.

The weak version does not say 60 of what.

## Answer Key with Explanations

1. Five values are below \(74\): \(52, 58, 61, 65, 70\).
2. \(\frac{5}{10}\times100=50\), so \(74\) is at the 50th percentile.
3. \(\frac{6}{10}\times100=60\), so \(74\) is at the 60th percentile using at-or-below.
4. Sample: In this data set, \(74\) is higher than 50% of the values.
5. The at-or-below rule includes \(74\) in the count, but the below-score rule does not.
6. Percentile rank describes relative standing, not percent correct. The 80th percentile means the score is higher than about 80% of the data values.
7. Sample: \(10, 12, 15, 18, 20, 22, 25, 28\). The score \(20\) has 4 values below it, and \(\frac{4}{8}\times100=50\).
8. \(\frac{18}{25}\times100=72\). The score is at the 72nd percentile, meaning it is higher than 72% of the class scores.

## Misconception Alerts

> [!WARNING] Misconception 1: "Percentile rank is the same as percent correct."
>
> Percent correct measures performance on an assignment. Percentile rank compares one score with other scores.

> [!WARNING] Misconception 2: "The target score is always counted."
>
> The target score is counted only when the problem uses the at-or-below convention.

> [!WARNING] Misconception 3: "A high percentile rank tells the exact highest score."
>
> Percentile rank shows relative position, not the maximum value or exact distance between scores.

## Error Analysis

A student writes:

> "There are 6 scores below 82, so the percentile rank is 6."

**Find the mistake:** The student counted correctly but forgot to divide by the total and multiply by \(100\).

**Correct reasoning:**

$$
\frac{6}{10}\times100=60
$$

The score \(82\) is at the 60th percentile using the below-score convention.

## Final Summary

Percentile rank compares one score with the rest of a data set. The core habit is simple but important: order the data, count correctly, divide by the total, multiply by \(100\), and write what the result means for the group.
