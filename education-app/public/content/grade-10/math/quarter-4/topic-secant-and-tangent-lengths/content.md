## What You Should Already Know

Before starting, make sure these ideas feel familiar:

- A **secant** is a line that intersects a circle at two points.
- A **tangent** touches a circle at exactly one point.
- Lengths in these problems are measured from one outside point.
- A **whole secant** equals the outside segment plus the inside segment.
- Solving may require dividing, factoring, or taking a square root.

### Pre-check / Readiness Quiz

Try these first. Then reveal the answers.

1. If the outside part of a secant is `4` and the inside part is `9`, what is the whole secant length?
2. What is `6(6 + 8)`?
3. If `x^2 = 81`, what positive length is `x`?
4. In a tangent-secant diagram, which segment gets squared?

<details>
<summary>Reveal pre-check answers</summary>

1. The whole secant length is `13`.
2. `6(14) = 84`.
3. `x = 9`, because lengths are positive.
4. The tangent length gets squared.

If these felt difficult, review parts of a circle and basic equation solving before continuing.
</details>

## Key Vocabulary

| Term | Meaning |
|---|---|
| External point | A point outside the circle where the segments begin |
| External segment | The part of a secant from the external point to the first point on the circle |
| Internal segment | The part of a secant inside the circle |
| Whole secant | External segment plus internal segment |
| Tangent segment | Segment from the external point to the tangent point |
| Power relationship | A product equation created by secants and tangents from the same external point |

> [!TARGET] Target Skill
>
> Translate a circle diagram into the correct equation, then solve for the missing length.

## Try Before You Read

Two secants start from the same point outside a circle. One has outside length `3` and inside length `9`. The other has outside length `4` and inside length `x`.

What should match: the outside parts only, the inside parts only, or the product of each outside part and its whole secant?

<details>
<summary>Reveal thinking guide</summary>

For secant-secant problems, use `external segment x whole secant` for each secant.
</details>

<details>
<summary>Reveal setup</summary>

`3(3 + 9) = 4(4 + x)`
</details>

## Main Concept 1: Secant-Secant Relationship

When two secants are drawn from the same external point:

`(external_1)(whole_1) = (external_2)(whole_2)`

![Secant-secant relationship diagram](/content/grade-10/math/quarter-4/topic-secant-and-tangent-lengths/images/secant-secant-relationship.svg)

The most common mistake is using the inside segment as the whole secant. The whole secant includes both parts.

### Worked Example 1

**Problem:** From point `P`, one secant has outside length `5` and inside length `7`. A second secant has outside length `4` and inside length `x`. Find `x`.

**Step 1: Write whole secants.**

- First whole secant: `5 + 7 = 12`
- Second whole secant: `4 + x`

**Step 2: Set up the relationship.**

`5(12) = 4(4 + x)`

**Step 3: Solve.**

`60 = 16 + 4x`

`44 = 4x`

`x = 11`

> [!CHECK] Reasonableness Check
>
> The second secant starts with a shorter outside segment, so it needs a longer whole secant to keep the products equal. An inside length of `11` is reasonable.

## Main Concept 2: Tangent-Secant Relationship

When a tangent and a secant are drawn from the same external point:

`(tangent)^2 = (external secant)(whole secant)`

![Tangent-secant relationship diagram](/content/grade-10/math/quarter-4/topic-secant-and-tangent-lengths/images/tangent-secant-relationship.svg)

The tangent is squared because it is paired with itself.

### Worked Example 2

**Problem:** A tangent from point `P` has length `12`. A secant from `P` has outside length `8` and inside length `x`. Find `x`.

**Step 1: Write the whole secant.**

Whole secant: `8 + x`

**Step 2: Set up the relationship.**

`12^2 = 8(8 + x)`

**Step 3: Solve.**

`144 = 64 + 8x`

`80 = 8x`

`x = 10`

## Choosing the Right Model

Use the segment types in the diagram before writing any equation.

![Choosing between secant-secant and tangent-secant models](/content/grade-10/math/quarter-4/topic-secant-and-tangent-lengths/images/choosing-the-right-model.svg)

| Diagram has... | Use this relationship |
|---|---|
| Two secants from the same external point | `(external_1)(whole_1) = (external_2)(whole_2)` |
| One tangent and one secant from the same external point | `(tangent)^2 = (external)(whole secant)` |

> [!WARNING] Common Length Traps
>
> Do not multiply the outside part by only the inside part. First build the whole secant.

![Common length traps diagram](/content/grade-10/math/quarter-4/topic-secant-and-tangent-lengths/images/common-length-traps.svg)

## Guided Practice

### Guided Problem 1

Two secants are drawn from point `A`. Secant 1 has outside length `6` and inside length `4`. Secant 2 has outside length `5` and inside length `x`. Find `x`.

<details>
<summary>Hint 1</summary>

The first whole secant is `6 + 4 = 10`.
</details>

<details>
<summary>Hint 2</summary>

Set up `6(10) = 5(5 + x)`.
</details>

<details>
<summary>Answer</summary>

`60 = 25 + 5x`, so `35 = 5x` and `x = 7`.
</details>

### Guided Problem 2

A tangent has length `9`. A secant from the same point has outside length `3` and inside length `x`. Find `x`.

<details>
<summary>Hint 1</summary>

Use tangent-secant: `(tangent)^2 = (external)(whole secant)`.
</details>

<details>
<summary>Hint 2</summary>

Set up `9^2 = 3(3 + x)`.
</details>

<details>
<summary>Answer</summary>

`81 = 9 + 3x`, so `72 = 3x` and `x = 24`.
</details>

## Final Checklist

Before moving to practice, you should be able to:

- Name whether a diagram shows secant-secant or tangent-secant.
- Add outside and inside parts to get the whole secant.
- Write the correct product equation.
- Solve for a missing inside, outside, or tangent length.
- Reject answers that make a length negative or unreasonable.
