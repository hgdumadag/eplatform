# Measurement and Geometry - Lesson 8: Square Pyramid Volume

> [!GOAL]
> Calculate the volume of square pyramids by finding the square base area, using the vertical height, and writing the answer in cubic units.

## Warm-Up: What Shape Is Being Filled?

Imagine a small square-based display box with four triangular sides meeting at one point.

Ask:

- What shape is the bottom base?
- What measurement tells how far the top point is straight above the base?
- If the box were filled with sand, what unit would measure the amount of sand?

Volume measures how much three-dimensional space a solid takes up or can hold.

## Square Pyramid Anatomy

A square pyramid has:

| Part | Meaning |
|---|---|
| Square base | The bottom face shaped like a square |
| Side length, `s` | One edge of the square base |
| Vertical height, `h` | The straight up-and-down distance from the base to the top vertex |
| Slant height | The distance along a triangular side face |

> [!IMPORTANT]
> Pyramid volume uses the vertical height, not the slant height. The vertical height is inside the pyramid and meets the base at a right angle.

## Formula

For a square pyramid:

`V = (1/3)s^2h`

where:

- `s` is the side length of the square base
- `s^2` is the base area
- `h` is the vertical height
- `V` is the volume

The answer uses cubic units, such as `cm^3`, `m^3`, or `in^3`.

## Why One-Third?

A square pyramid with the same base area and vertical height as a square prism has one-third of the prism's volume.

| Solid | Volume idea |
|---|---|
| Square prism | `base area x height` |
| Square pyramid | `1/3 x base area x height` |

So the formula can also be written as:

`V = (1/3)Bh`

For a square base, `B = s^2`, so:

`V = (1/3)s^2h`

## Worked Example: Find the Volume

A square pyramid has base side length `6 cm` and vertical height `9 cm`. Find its volume.

Step 1: Find the base area.

`s^2 = 6^2 = 36`

The base area is `36 cm^2`.

Step 2: Multiply by the vertical height.

`36 x 9 = 324`

Step 3: Take one-third.

`V = (1/3)(324) = 108`

Answer: The volume is `108 cm^3`.

> [!TIP]
> A quick routine is: square the side length, multiply by the vertical height, then divide by 3.

## Common Trap: Slant Height

Suppose a square pyramid has:

- base side length `8 cm`
- vertical height `6 cm`
- slant height `10 cm`

For volume, use `6 cm`, not `10 cm`.

`V = (1/3)(8^2)(6)`

`V = (1/3)(64)(6) = 128`

The volume is `128 cm^3`.

The slant height may help with surface area later, but it is not the height used for volume.

> [!WARNING]
> If a problem says "height along the triangular face," that is slant height. Look for the vertical height before calculating volume.

## Unit Check

Use cubic units because volume measures three dimensions.

| Given lengths | Volume unit |
|---|---|
| centimeters | `cm^3` |
| meters | `m^3` |
| inches | `in^3` |
| feet | `ft^3` |

Do not write square units for volume. Square units are for area.

## Guided Practice

1. A square pyramid has side length `5 cm` and vertical height `12 cm`. Find its volume.
2. A square pyramid has side length `9 m` and vertical height `4 m`. Find its volume.
3. A square pyramid has base area `49 in^2` and vertical height `15 in`. Find its volume.
4. A square pyramid has side length `10 ft`, vertical height `6 ft`, and slant height `8 ft`. Which height should be used for volume?
5. A student writes `75 cm^2` as the volume of a square pyramid. What unit error should be fixed?

Answers:

1. `100 cm^3`
2. `108 m^3`
3. `245 in^3`
4. Use the vertical height, `6 ft`.
5. The unit should be `cm^3`, not `cm^2`.

## Final Checklist

Before taking the practice exam, make sure you can:

- identify the square base side length
- calculate base area with `s^2`
- use the vertical height in `V = (1/3)s^2h`
- ignore slant height when finding volume
- write volume answers with cubic units

> [!PRACTICE]
> Use the practice questions for quick checks on formula use. Use the assessment when you can identify base area and vertical height without mixing them up with slant height.
