# Measurement and Geometry - Lesson 7: Pyramid Volume Exploration

> [!GOAL]
> Compare a prism and a pyramid with the same base and height. Use the comparison to explain why a pyramid's volume is `one-third` of the matching prism's volume.

## Opening: Same Base, Same Height

Imagine a rectangular box and a rectangular pyramid that sit on the same base.

- The box has a rectangular floor.
- The pyramid has the same rectangular floor.
- Both have the same vertical height.

Question to notice: Does the pyramid hold as much as the box?

It does not. A pyramid narrows to one top point, so it holds less. In this lesson, you will explore exactly how much less.

## Key Vocabulary

| Term | Meaning |
|---|---|
| Base | The face used as the bottom of a solid |
| Base area, `B` | The area of the base |
| Height, `h` | The perpendicular distance from the base to the opposite face or top point |
| Prism | A solid with matching parallel bases and the same cross-section along its height |
| Pyramid | A solid with one base and triangular faces that meet at one point |

> [!IMPORTANT]
> The height of a pyramid is not usually the slanted edge. Use the straight, perpendicular height from the base to the top point.

## Core Idea: Three Matching Pyramids Fill One Prism

If a pyramid and a prism have the same base area and the same height, the pyramid has `one-third` of the prism's volume.

That means:

`1 pyramid + 1 pyramid + 1 pyramid = 1 matching prism`

So:

`pyramid volume = prism volume / 3`

Since prism volume is:

`V = Bh`

pyramid volume is:

`V = (1/3)Bh`

where:

- `B` is the base area
- `h` is the perpendicular height

## Exploration: Filling a Prism

Suppose you have:

- a rectangular prism with base `6 cm` by `4 cm`
- a pyramid with the same `6 cm` by `4 cm` base
- both solids have height `9 cm`

The prism volume is:

`V = Bh`

`B = 6 x 4 = 24 cm^2`

`V = 24 x 9 = 216 cm^3`

If three matching pyramids fill the prism, then one pyramid has:

`216 / 3 = 72 cm^3`

The pyramid volume is `72 cm^3`.

> [!TIP]
> You can think of `V = (1/3)Bh` as "find the matching prism first, then take one-third."

## Worked Example: Square Pyramid

A square pyramid has a base side length of `5 m` and a height of `12 m`. Find its volume.

Step 1: Find the base area.

`B = 5 x 5 = 25 m^2`

Step 2: Use the pyramid volume formula.

`V = (1/3)Bh`

Step 3: Substitute and calculate.

`V = (1/3)(25)(12)`

`25 x 12 = 300`

`300 / 3 = 100`

The volume is `100 m^3`.

## Scaffolded Task: Build the Formula

A rectangular pyramid has length `10 cm`, width `6 cm`, and height `9 cm`.

1. Find the base area: `B = ___ x ___ = ___ cm^2`
2. Find the matching prism volume: `Bh = ___ x ___ = ___ cm^3`
3. Take one-third: `___ / 3 = ___ cm^3`
4. Write the pyramid formula: `V = ___`

Check:

1. `B = 10 x 6 = 60 cm^2`
2. `Bh = 60 x 9 = 540 cm^3`
3. `540 / 3 = 180 cm^3`
4. `V = (1/3)Bh`

## Common Mistakes

> [!WARNING]
> Do not forget the factor `1/3`. If you calculate only `Bh`, you found the volume of the matching prism, not the pyramid.

> [!WARNING]
> Do not use square units for volume. Base area uses square units, but volume uses cubic units.

4. A prism has volume `150 cm^3`. A matching pyramid has the same base and height. What is the pyramid's volume?

Answers:

5. Three matching pyramids fill one prism with the same base and height, so one pyramid is one-third of the prism.
