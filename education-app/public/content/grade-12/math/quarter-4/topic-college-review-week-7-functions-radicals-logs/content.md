# College Review Week 7: Functions, Radicals, and Logarithms

## Weekly Goal

This week targets the student's higher-level algebra habits: substitution, domain awareness, checking radicals, and using logarithm rules correctly. The biggest improvement goal is not speed. It is **accuracy with restrictions**.

## Session 1: Function Notation and Domain Awareness

**Target time:** 45-60 minutes

### Warm-Up Recall

1. If $f(x) = 2x + 3$, find $f(4)$.
2. If $g(x) = x^2 - 1$, find $g(-3)$.
3. What restriction appears in a denominator?

### Core Idea 1: Function Notation Means Substitute Carefully

**Example 1:**  
If $f(x) = 3x^2 - 2x + 1$, find $f(-2)$.

$$f(-2) = 3(-2)^2 - 2(-2) + 1 = 12 + 4 + 1 = 17$$

### Core Idea 2: Domain Checks Prevent Impossible Answers

- Denominator cannot be zero
- Even root cannot contain a negative number in real-number problems
- Logarithm input must be positive

**Example 2:**  
For $h(x) = \frac{1}{x-5}$, $x \neq 5$.

## Session 2: Radicals and Logarithms

**Target time:** 45-60 minutes

### Radical Equations

Solve, then check the answer in the original equation.

**Example 3:**  
Solve:

$$\sqrt{x+5} = x-1$$

Square both sides:

$$x + 5 = (x-1)^2$$

$$x + 5 = x^2 - 2x + 1$$

$$0 = x^2 - 3x - 4$$

$$0 = (x-4)(x+1)$$

Candidates: $x=4$ or $x=-1$

Check:

- $x=4$: $\sqrt{9}=3$ and $4-1=3$ works
- $x=-1$: $\sqrt{4}=2$ but $-1-1=-2$ does not work

So the answer is **4**.

### Logarithm Rules

- $\log(ab) = \log a + \log b$
- $\log\left(\frac{a}{b}\right) = \log a - \log b$
- $\log(a^n) = n\log a$

**Example 4:**  
Solve:

$$\log x + \log 4 = 2$$

$$\log(4x) = 2$$

$$4x = 10^2 = 100$$

$$x = 25$$

## Session 3: Timed Higher-Algebra Checkpoint

**Target time:** 45 minutes

### Mini Drill

1. If $f(x)=x^2+2x$, find $f(3)$.
2. Solve $\sqrt{x+1}=5$.
3. Solve $\log x = 3$.

### Final Worked Example

**Example 5:**  
Solve:

$$\sqrt{2x+3} + 1 = 6$$

$$\sqrt{2x+3} = 5$$

$$2x+3 = 25$$

$$2x = 22$$

$$x = 11$$

Check:

$$\sqrt{25}+1=5+1=6$$

### End-of-Week Checklist

- I substitute into functions carefully.
- I check domain restrictions before finalizing answers.
- I verify radical-equation answers in the original equation.

## Key Takeaways

- Strong algebra students check restrictions before they simplify.
- Radical equations often create fake answers if you do not check.
- Logarithms are controlled by one rule that never changes: the input must stay positive.
