- **Estimated time:** 50–60 minutes

## What You Should Already Know

- Balanced forces do not change an object's motion, while unbalanced forces can.
- Speed, direction, and motion can be described using words, numbers, arrows, and diagrams.
- Simple circuits need a source, conductors, and a complete path.
- Waves transfer energy from one place to another.

## Key Vocabulary

| Term | Meaning |
|---|---|
| **series circuit** | circuit with one path for current |
| **parallel circuit** | circuit with multiple branches |
| **branch** | separate path in a parallel circuit |
| **ammeter** | meter connected in series to measure current |
| **voltmeter** | meter connected across a component to measure voltage |

## Main Concept Explanation

In a series circuit, components are arranged in one loop, so the same current passes through each part and one break stops the entire circuit. In a parallel circuit, components are connected on separate branches. Each branch can still work even if another branch opens, which is why home circuits are arranged in parallel.

### Learning Objectives

- Compare series and parallel circuit paths.
- Predict what happens when one load fails.
- Identify circuit symbols for common parts.
- Explain why homes use parallel wiring.

> [!NOTE]
> **Key idea:** In Physics, do not only memorize words. Connect each word to a diagram, a cause, and an observable effect.

## Misconception Alerts

- **Common mistake:** Parallel circuits are not “weaker” because current splits. Each branch can receive the source voltage, while total current depends on the branch loads.
- Do not confuse a description with an explanation. A description says what happens; an explanation says why it happens.
- Check whether forces act on the same object or on different objects before deciding if they cancel.

## Error Analysis

A learner says: “The biggest arrow or most energetic wave is always the correct answer.” This is incomplete. A good Physics explanation must match the **specific situation**. Ask: What object or wave is being studied? What quantity changed? What evidence supports the answer?
